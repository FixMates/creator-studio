# Demo Storefront QA

Status: Pending implementation and per-store verification.

For each demo store, verify:
- [ ] Store identity and distinct branding
- [ ] Three meaningful banner slides and working CTAs
- [ ] Products have traceable genuine listing URLs, or are explicitly marked illustrative
- [ ] Prices are verified and timestamped, or displayed as unavailable
- [ ] Product images are genuine and authorized for use
- [ ] No duplicate or fabricated product claims
- [ ] Store WhatsApp action does not imply a real seller contact when no authorized number exists
- [ ] Product WhatsApp action includes correct product context
- [ ] External product links preserve legitimate affiliate parameters
- [ ] Product and banner click analytics are distinct
- [ ] Mobile layout and keyboard navigation pass

No demo store is marked verified until its individual source register and browser checks are complete.
